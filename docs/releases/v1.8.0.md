# v1.8.0 — консоль обновления в панели + доступный бэкап + фикс кэша версий

## Обновления (панель «Гео-маскировка и AI»)

- **Пошаговый лог списком** (как консоль Zapret-Manager): каждый шаг самообновления
  (queued/backup/download/validate/apply/done/error) дописывается **новой строкой** в
  `/tmp/geomask-upd/steps.log` и выводится в тёмной консоли под кнопкой обновления —
  вместо прежней одной заменяемой строки статуса. Автопрокрутка, цвета по фазе
  (идёт — жёлтый, готово — зелёный, ошибка — красный). Одинаковые строки не перерисовываются.
- Тот же поток шагов дублируется в общий журнал `/root/geo-sync.log` (`GEOMASK-UPD [...]`),
  который показывается в карточке «Журнал» — обновление видно по всем действиям панели.
- **Бэкап перед обновлением стал видимым**: фаза backup пишет в лог полный путь, размер и
  md5 архива (`/tmp/router-backup-<ts>.tar.gz`, tmpfs — исчезает после перезагрузки) и
  команду забора на ПК; в репозитории — рабочий `fetch_backup.ps1` (сам находит свежий
  архив на роутере, скачивает, сверяет md5, кладёт в `Y:\openwrt\backup\`).
  Восстановление — штатно: LuCI System → Backup / Flash Firmware → Restore.
- **Фикс «версия не обновилась»**: после успешного применения runner удаляет кэш
  `check.json` — страница при перезагрузке делает свежую проверку и показывает реально
  установленные версии (раньше кэш 1 ч возвращал «local» до-обновленческого состояния).
- Текст-подсказка блока «Обновления» дополнен (лог, судьба бэкапа, восстановление).
- `geomask --backup` теперь явно напоминает про перенос архива на ПК (политика 22.10).

## Совместимость

- `upd_status` JSON дополнен полем `lines` (массив строк); прежние поля не изменились —
  старая страница работает с новым бэкендом и наоборот до перезагрузки страницы.
- Пустой `/tmp` после перезагрузки: консоль скрывается до первого обновления.
