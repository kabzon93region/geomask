# geomask v1.15.0 — торренты: убрали опасные портовые правила, добавили управление в панели

## 1. Правила DST-PORT для P2P-портов удалены полностью

В v1.14.4 шесть правил (`DST-PORT,6969/1337/2710/8081/451/5944`) были переведены из VPN в DIRECT.
Это была половинчатая мера: правило стоит **в начале списка, выше `RULE-SET,ai,AI`**, и потому
перехватывает **любой** трафик этих портов — включая AI-релеи, которые на них оказываются.

Замер на роутере подтвердил реальность риска: `45.155.204.190:1337` — comss-релей AI — попадал под
портовое правило вместо политики AI. После удаления:

```
45.155.204.190:1337   match RuleSet(ai) using AI[🇺 USA 6 VLESS TCP]   ← как и должно
211.75.205.187:6969   match Match using GLOBAL[DIRECT]                ← трекер: как и должно
```

Теперь закреплён только адресно-доменный механизм (`torrentdirect`) и прокси-слушатель.
`--check` считает любое такое правило легаси-ошибкой (`bad`), шаблон его больше не пишет.

## 2. Управление фичей в панели geomask

Вкладка «Списки и синк» → карточка **«Торренты и трекеры»**:

- состояние слушателя `torrent-direct` (порт, адрес `socks5h://192.168.0.1:7894`) и кнопки
  «Включить слушатель» / «Выключить слушатель»;
- число доменов и IP в ruleset + счётчик правил, которые **реально загрузил mihomo**
  (`/providers/rules`) — это ловит ситуацию «файл обновили, а ядро не перечитало»;
- «Обновить списки трекеров» — пересобрать ruleset из публичных источников;
- поле «свои домены» — свои трекеры, подмешиваются к спискам при каждой пересборке.

Реализация — `/usr/bin/geomask-torrent.sh` (`--status`, `--refresh`, `--listener on|off`,
`--extra "..."`). Конфиги: `/etc/geomask/torrent/sources.conf` (источники) и
`/etc/geomask/torrent/extra.txt` (свои домены) — между обновлениями сохраняются.

Безопасность записи: любое изменение `config.yaml` или ruleset проходит `mihomo -t` и **откатывается
при ошибке**; перезагрузка — PUT `/configs` с bearer-токеном, секрет в argv не попадает. Свои домены
валидируются регуляркой, недопустимые отклоняются с перечислением.

Методы `torrent_get` / `torrent_refresh` / `torrent_listener` / `torrent_extra` зарегистрированы в
бэкенде, rpcd-wrapper и ACL — как того требует S19 (та же ловушка, из-за которой v1.13.0 упала с
«Access denied» сразу после релиза).

## Тесты

Новый сценарий **S24** (22 проверки): наличие скрипта и его режимов, подключение в build MAP,
установка/проверка/очистка в установщике, наличие каждого метода во **всех трёх** местах,
карточка и потребление нового слота промисов панелью. S23 переведён на новую формулировку
(«no blanket P2P port rules»), фикстура «здорового роутера» очищена от портового правила.
Песочница: **175** проверок, юнит-тесты: 16.

## Обновление

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@v1.15.0/geomask.sh' && sh /tmp/geomask.sh
```

После обновления перезагрузите страницу панели (Ctrl+F5) — появится карточка «Торренты и трекеры».
Подробности: [docs/TORRENTS.md](TORRENTS.md).
