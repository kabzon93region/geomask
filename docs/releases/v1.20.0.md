# geomask v1.20.0 — направление выбирает список, а не пин; флаги серверов вернулись

## 1. Убраны 5 жёстких DIRECT-пинов

В самом верху цепочки правил лежали строки:

```
- DOMAIN-SUFFIX,thepiratebay.org,DIRECT
- DOMAIN-SUFFIX,rutracker.org,DIRECT
- DOMAIN-SUFFIX,rutracker.net,DIRECT
- DOMAIN-SUFFIX,rutracker.wiki,DIRECT
- DOMAIN-SUFFIX,rutracker.cc,DIRECT
```

Они стояли **раньше всех** `RULE-SET`, поэтому перенос этих доменов в любую группу MagiTrickle
ничего не менял: пин перебивал выбор владельца. Проверено живьём — `match DomainSuffix(rutracker.org)
using DIRECT` при том, что домен был и в `mtrickle.yaml`.

Пины убраны и из конфига, и из шаблона (иначе переустановка вернула бы их обратно). Торрент-сайты
теперь едут туда, куда их поместила группа: в прямую группу с интерфейсом `pppoe-wan`, то есть
**после запрета, напрямую, без туннеля**. Направление выбирается в одном месте — в списке.

## 2. Флаги серверов в панели

«Пропали банеры у обычного VPN» — рендер, а не связь и не перегрузка движка. API отдаёт имена
вместе с флагами (`🇦🇱 Албания-1 · Reality`, 35 узлов; `🇺🇸 USA 6 VLESS TCP`, 6 узлов), бэкенд считает
код страны правильно (`vpn_cc=AL`, `ai_cc=US`), но `cleanName()` в панели вырезает символы флагов,
а `ccBadge()` показывал только две буквы.

Теперь бейдж несёт флаг, взятый из исходного имени (`flagOf()`), и вызывает name все три слота:
`AI`, `VPN-noP2P`, `VPN`. Текст узла по-прежнему чистый — флаг не дублируется.

## 3. Аудит заблокированной подписки — подтверждён

За ночь накопилось 230 записей, у каждой есть источник, **голых IP-назначений 0**. Последние записи
остановились на 22:09 — ровно после перевода основной полосы на живую подписку: попытки попасть в
заблокированную слот прекратились, потому что на него больше не указывает ни одно правило. Пустой
отчёт утром — это и есть признак безопасности, а не поломки сборщика.
