# geomask v1.16.2 — кнопку «Проверить сейчас» в карточку обновлений

## Почему так

Панель показывала «Доступно на GitHub 1.16.0», хотя 1.16.1 уже был выпущен. Это не поломка:
ответ GitHub кэшируется в `/tmp/geomask-upd/check.json` на **60 минут** — специально, потому что
неавторизованный API GitHub ограничена ~60 запросами в час с адреса, а панель перечитывается часто.

Но из-за этого свежий релиз не виден до часа, и это выглядит как «обновление не вышло».

## Что добавлено

В карточке обновлений — строка с пояснением и кнопка **«Проверить сейчас»**, которая вызывает
`upd_check` с `force` (параметр был прокинут от бэкенда до панели с самого начала, просто
никто его никогда не передавал) и перезагружает данные.

Установленные компоненты при этом и так считаются живьём с диска (v1.14.2), так что теперь
в карточке нет ни одного устаревшего поля.
