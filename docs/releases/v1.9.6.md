# v1.9.6 — упрощённый вход в шар бэкапов

По просьбе владельца: доступ «проще» — пользователь `backup` / пароль `backup`, папка только для чтения.

- ensure_smb_share: фиксированная учётка `backup` (ksmbd.adduser, идемпотентно); механизм
  генерации случайного пароля и файл `/root/.geomask-smb.pass` убраны.
- Шар гостевой (guest ok) + read only + force user root — с устройств, не блокирующих
  небезопасный гость (телефоны, TV, проводник после гостевого запрета в Windows), открывается
  вообще без пароля; Windows-совместимый вариант — `backup`/`backup`.
- Панель: строка учётки показывает `backup / backup`, команда net use копированием.
- Проверено с Win-ПК: гостевой листинг работает без всякого net use (по-policy-исключению
  клиента), запись отклонена.
