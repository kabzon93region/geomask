# geomask v1.13.6 — починка ночного скана узлов + свежий шаблон списков

## Что сломалось и почему

Провайдер VPN-подписки сменил формат выдачи: вместо base64/ссылок теперь отдаётся **целый
YAML-конфиг**, где у прокси `server:` стоит не на строке сразу после `name:`, а ниже (между ними
`type:`, `port:` и прочее). Старый парсер требовал соседнюю строку и поэтому распознавал **1 узел
из 39**. Скан в 11:43 молча применил `exclude-filter` без точечных банов — так из фильтра исчезли
прежние запреты (Турция и др.).

## Исправлено

- **Парсер YAML** (`geomask-node-scan.sh`): обход элементов списка, `server:` ищется в пределах
  своего узла независимо от числа промежуточных полей; поддержан flow-стиль `- {name: …, server: …}`;
  записи без `server:` (proxy-groups) игнорируются.
- **Страховка от тихой деградации**: если распознано меньше `MIN_NODES=3` узлов, скан **не
  переписывает** фильтр и завершается с внятным сообщением — вместо незаметной потери банов.
- **Свежий шаблон списков** (`assets/magitrickle-groups.yaml`, `templates/lists.meta.json`):
  26 групп (добавилась «GoogleVideo VPN»), группа «Telegram» — `interface: Mihomo`, `enable: true`
  (Telegram Web через VPN). sha256 шаблона обновлён.

## Список узлов теперь банится по факту, а не по имени

В `base_filter` добавлены `🇷`, `без рекламы`, `Turkey`, `United Kingdom`; в `bad_countries` — `TR`;
в `bad_asns` — `AS207847` (CloudBlast/OАЭ, узлы с вывеской «United Kingdom»). Это закрыло
реально найденные дыры: российский узел `🇷 YouTube без рекламы` (AS215590, Москва) и турецкие
узлы попадали в группу VPN, потому что в именах не было слов из фильтра.

## Тесты

- Новые регресс-тесты `tests/test_nodescan_parse.py` (4): YAML с полями между `name:`/`server:`,
  flow-стиль, пропуск групп без `server:`, наличие страховки `MIN_NODES`.
- Юнит-тесты: 8/8. Песочница `run_tests.sh`: 120/120.

## Обновление

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@v1.13.6/geomask.sh' && sh /tmp/geomask.sh
```

После обновления стоит разок запустить скан вручную (`/usr/bin/geomask-node-scan.sh`) — он заново
обойдёт все узлы по гео/ASN и вернёт точечные баны.
