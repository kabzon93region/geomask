## 2. Локальные проверки

- Финальное независимое ревью (R09/R06/P3) приняло участки; найденные им дефекты исправлены в `f5d547d`: манифест падает на удалённом модуле, сбой redactor в архиве даёт валидный JSON и уборку, лимит 384 КиБ стал жёстким (попутно исправлен `_diag_uint`, раздувавший default до 1 МиБ), сценарный раннер считает timeout и unknown skip.

- 29 модулей, **497 тестов OK**, 12 skip (только POSIX/Linux-причины).
- Сценарий S11 (`GM_SCENARIO_FILTER=S11`): pass=7 fail=0, verdict=PASS, 5 прогонов подряд rc=0. Ранее был флейки: синхронный `drain` гонялся с отделённым worker hotplug (оба берут `routes-worker`) — тест теперь ограниченно ждёт применения очереди.
- `check_build --verify-only`: OK, артефакт `bf0ae47160d07758`.
- Clean clone (`git clone` → `build.py`): артефакт байт-в-байт тот же; `build_module_index.py` ничего не меняет; `gen-geo-rpc.py --check` OK (66 методов).
- `bash -n` (geomask.sh, assets), `node --check`, `git diff --check` — чисто.
- Дерево чистое, 10 коммитов за проход (`71d7bde`…`f5d547d`), 24 коммита впереди `origin/master`, push не делался.

## 3. Что НЕ закрыто (честно)

- **R06 остаток**: Linux namespace/strace-job для доказанного запрета живых путей не реализован (на Windows невозможен) — задокументирован как pending; POSIX-hardlink тест в suite на Windows скипается (логика проверена отдельным сравнением); `expected-counts.json` — статические минимумы, финализируются на стенде.
- **R11 стенд**: clean-room Linux/OpenWrt прогон полного suite, реальные UCI/BusyBox/mihomo/hev/fw4, fault injection, ifup storm — не выполнялись (нет стенда, Windows их не доказывает).
- **G02/G03/G05, N03, N09**: OPEN, вне объёма R10 (см. `docs/GN-MAPPING.md`).
- **D14**: периодический dnsguard/dnscheck не добавлен — это политика владельца (restart dnsmasq/смена upstream), не техническое исправление.
- **phase2a–2f** не перезапускались после R05/R09/R10/R12: эти изменения не трогают snapshot/restore; последний полный зелёный прогон был на `71d7bde`, а manifest/preflight/install перепрогнаны сейчас.
- **Независимое ревью**: R08 принято (77 тестов, RED воспроизведён на копиях до фикса), замечания исправлены в `bbc2ed1`; R10a принято (контракт guard/dnscheck подтверждён, RED на копиях `b061698^`), три P3 — чужое правило при `enabled=1`, хвостовая точка в IP, молчаливый пропуск нечитаемого `console.state` — исправлены в `5fda9e4`.
- **Рабочий роутер** не использовался вообще; установка/переустановка/обновление/смена DNS/console не выполнялись.

## 4. Готовность

- **Изолированный OpenWrt-стенд**: код и тесты к нему готовы (детерминированные RED, инжектируемые пути, отсутствие записей в live-каталоги в новых тестах), но требуется прогон на стенде и запись версий.
- **Массовое использование / рабочий роутер**: НЕ готово. Нет стендовой приёмки, нет проверки реального iproute2/BusyBox/procd/netifd/fw4/ksmbd, не проверены UDP/MTU, рестарты, DNS-leakage, транспорт base64-RPC. Пилот — отдельное решение владельца со свежим полным бэкапом и проверенным rollback.
