# v1.9.1 — ensure_smb_share: корректное создание секции uci

- `uci set ksmbd.@share[last]...` не поддерживается uci — v1.9.0 создал пустую секцию
  `config share` без опций, шар не появился в `ksmbd.conf` (проверено на роутере, --check
  честно показал fail). Теперь: имя секции берётся из вывода `uci add ksmbd share`, поиск —
  перечислением секций по `uci show` (индексы `@share[N]` не ломались бы на пустых секциях,
  но `last` ломался всегда), а leftover-пустые секции (созданные v1.9.0) удаляются при
  следующем прогоне шага geo.
- Тест S13+: запрет `@share[last]`, наличие захвата секции.
