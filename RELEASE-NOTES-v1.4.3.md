## geomask v1.4.3

UI-фиксы панели «Подписки».

### Исправлено

- **Путаница «включено/нет»**: у неактивной подписки обе кнопки были залиты сплошным синим и выглядели как активные бейджи. Теперь кнопки нейтральные, текущее назначение показывается только бейджем в колонке «Назначение» (VPN / AI / VPN + AI / —), а кнопка активного назначения отключена.
- **Раскладка**: таблица подписок вылезала за пределы карточки из-за длинных URL. Теперь `table-layout:fixed`, ссылка переносится по символам, колонки фиксированной ширины.
- Уточнён текст подсказки (что показывают бейджи и кнопки).

Переключение подписок (кнопки «→ VPN»/«→ AI») работает штатно: конфиг mihomo патчится с бэкапом, провайдер обновляется через API без рестарта — проверено вживую (переключение AI на USA и обратно).

### Установка

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh
```
