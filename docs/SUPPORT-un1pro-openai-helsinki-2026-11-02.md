## Приложение: как воспроизвести (для инженера un1.pro)

```bash
# для любого USA-узла подписки (как SOCKS/HTTP-прокси или через клиент):
curl -x http://<proxy> https://chatgpt.com/cdn-cgi/trace | grep -E '^(ip|colo|loc)='
curl -x http://<proxy> https://www.cloudflare.com/cdn-cgi/trace | grep -E '^(ip|colo|loc)='
# Ожидаем: cloudflare -> ip=<US-адрес узла> loc=US ; chatgpt -> ip=144.31.129.189 loc=FI colo=HEL
```

## Замечание по методике поддержки
Их «контрольные подключения», вероятно, проверяют обычный исходящий IP (cloudflare/whoer) — он и правда US.
Нужно проверять **именно `chatgpt.com/cdn-cgi/trace`** (или фактический IP, который видит OpenAI), тогда
Хельсинки воспроизводится на всех USA-узлах.
