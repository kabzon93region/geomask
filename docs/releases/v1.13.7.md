# geomask v1.13.7 — скан узлов снова видит подписку (User-Agent + Bearer)

## Что на самом деле ломало ночной скан

Провайдер (панель Remnawave) **отдаёт заглушку из одного «узла»** —
`vless://00000000-…@0.0.0.0:1#Приложение не поддерживается` — клиентам, которых не узнаёт.
Скан слал запрос без `User-Agent` (питоновый `Python-urllib/3.13`) и получал именно её:
`total=1, blocked=0`. Заодно в 11:43 это успело **стереть точечные баны** из `exclude-filter`.

Замеры с роутера (5 попыток на каждый UA):

| User-Agent | Ответ |
|---|---|
| `clash-meta` | YAML-конфиг, **39 узлов**, 5/5 |
| `v2rayNG`, `NekoBox/Android`, `kitsunebi` | base64, 38 ссылок, 5/5 |
| `clash` или **без UA** | заглушка на 1 «узел» |

## Исправлено

- **`sub_user_agent`** (по умолчанию `clash-meta`) — скан представляется известным приложением;
  значения задаётся в `/etc/geomask-nodes.conf`.
- **3 попытки загрузки** с паузой вместо одного запроса.
- **Bearer для перезагрузки конфига**: `PUT /configs` в скане падал с `401 Unauthorized`
  (тот же класс бага, что исправлен в v1.13.5 для установщика/бэкенда/синка — про скан я забыл).
- **Страховка `MIN_NODES=3`** (добавлена в v1.13.6): при подозрительно малом числе узлов скан
  **не переписывает** фильтр. Именно она и не дала испортить конфиг дальше.
- **Парсер YAML** (v1.13.6) теперь реально используется: с `clash-meta` приходит YAML, где
  `server:` не соседняя строка.

## Обновлённая политика банов (`/etc/geomask-nodes.conf`)

- `bad_countries=RU,BY,KZ,IR,TR` — Турция возвращается в бан (её точечный бан пропал со стиранием фильтра).
- `bad_asns=AS210976,AS215540,AS207847` — добавлен CloudBlast (ОАЭ): узлы с вывеской «United Kingdom» на самом деле в AE.
- `base_filter` дополнен `Turkey`, `United Kingdom`, `🇷🇺`, `без рекламы` — российский узел
  `🇷 YouTube без рекламы` (AS215590, Москва) проходил фильтр, потому что в имени не было ни одного
  из прежних слов: эмодзи-флаг страной по имени не считается.

## Обновление

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@v1.13.7/geomask.sh' && sh /tmp/geomask.sh
```

После обновления — разок запустить `/usr/bin/geomask-node-scan.sh`: он заново обойдёт узлы по
гео/ASN и вернёт точечные баны (проверить: `/tmp/geomask-nodescan.state`, `total` должен быть ~39).
