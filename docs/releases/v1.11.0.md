# v1.11.0 — ночной аудит узлов подписки (анти-утечка «новый сервер = РФ»)

Автономная проверка каждого узла VPN-подписки без переключения трафика:

- **geomask-node-scan.sh** (cron 03:30 + кнопка «Проверить узлы сейчас» в панели):
  скачивает подписку, разбирает адреса серверов всех узлов, для каждого смотрит страну и ASN
  в гео-базе; узел с «плохой» меткой **блокируется точным именем** в exclude-filter группы
  VPN, чистый — снимается из блока. Конфиг пересобирается только при изменениях, проходит
  `mihomo -t` и применяется hot-reload'ом; при провале валидации — откат, конфиг нетронут.
- **/etc/geomask-nodes.conf** — правила: `bad_countries` (RU,BY,KZ,IR), `bad_asns`
  (AS210976 Timeweb, AS215540 GCS — из расследования plati). Базовый
  `base_filter` имён. Файл редактируется руками, переустановка geomask его сохраняет.
- Итог скана пишется в карточку стека (когда/сколько узлов/сколько заблокировано) и в
  `/root/geo-sync.log` одной строкой.
- Ограничение (честно): гео-база смотрит регистрацию адреса; узел с «европейской» меткой,
  но физически в РФ (как Нидерланды-18 от Timeweb) ловится по bad_asns, а не по стране —
  свежие сети нужно при желании дописать в conf. Сбой lookup = узел НЕ блокируется (не
  ломаем доступ из-за чужих таймаутов).
