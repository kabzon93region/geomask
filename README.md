# geomask

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/kabzon93region/geomask)](https://github.com/kabzon93region/geomask/releases/latest)

Надстройка над OpenWrt, которая собирает и держит в порядке стек маршрутизации: **mihomo**
(группы `VPN`, `VPN-noP2P`, `AI`), **MagiTrickle** (доменные группы → метки nftables →
туннели), **hev-socks5-tunnel** (TUN → SOCKS), **zapret** (обход DPI) и панель LuCI
«Гео-маскировка и AI» с центром диагностики.

Целевой стенд — **wwGate AX3000 (MediaTek Filogic, aarch64)**, OpenWrt 25.12.x. Другие
устройства не запрещены, но и не обещаны: установщик проверяет окружение и говорит, чего
не хватает, вместо того чтобы делать вид, что всё хорошо.

## Что нужно до установки

| | |
|---|---|
| OpenWrt | с `apk` (25.x) или `opkg` (24.x и старше) |
| обязательно | `mihomo` и `magitrickle` уже установлены — geomask настраивает их, а не заменяет |
| поставит сам | `python3`, `curl`, `https-dns-proxy` (для AI-DNS) — через `apk`/`opkg` |
| по желанию | `zapret`, `hev-socks5-tunnel`, `tg-ws-proxy` — если нужны соответствующие пути |

`mihomo` и `magitrickle` в официальных фидах OpenWrt отсутствуют, поэтому установщик не
пытается ставить их сам: на шаге 1 он прямо говорит, что это надстройка и что поставить
сначала. Всё остальное, что есть в фидах, ставится автоматически.

## Установка

```sh
# 1. отчёт без изменений: что есть, чего нет, что будет сделано
wget -O /tmp/geomask.sh https://github.com/kabzon93region/geomask/releases/latest/download/geomask.sh
sh /tmp/geomask.sh --check

# 2. установка без вопросов (шаги идут по порядку и останавливаются на первом FAIL)
sh /tmp/geomask.sh --auto

# 3. что за модули вообще бывают и какие обязательные
sh /tmp/geomask.sh --list-modules
```

Полезные режимы:

| команда | что делает |
|---|---|
| `--check` | только чтение: отчёт по семи шагам, ничего не меняет |
| `--auto` | все шаги без вопросов, стоп на первом FAIL |
| `--step N` | один шаг: 1 env, 2 geo, 3 subs, 4 aidns, 5 sync, 6 services, 7 verify |
| `--modules=core,luci,guard,path_vpn` | набор модулей без интерактивного меню |
| `--reinstall` | переустановка поверх (файлы, панель, модули) |
| `--backup` | полный `sysupgrade -b` и выход |
| `--seed-lists` | восстановить доменные списки MagiTrickle из шаблона |
| `--restart` | разрешить перезапуск mihomo/magitrickle там, где он нужен (VPN рвётся на ~3 с) |

Без `--restart` установщик и обновление не перезапускают сервисы.

## Панель

LuCI → «Гео-маскировка и AI», девять вкладок:

**Обзор** (состояние путей, журнал) · **Устройства** (режимы: туннель / исключение /
AI) · **Подписки** (VPN и AI, обновление, переключение) · **Списки и синк** (группы
MagiTrickle, шаблоны) · **Узлы подписки** (аудит серверов) · **Диагностика** ·
**Бэкапы** · **Модули** (версии и обновление частей + релиз целиком) · **Настройки**.

## Модули

Пятнадцать модулей, у каждого своя версия и отдельное обновление:

`core` (ядро: синк, node-audit, лейн, списки) · `luci` (админка: страница, бэкенд, RPC,
ACL, меню) · `guard` (сторож маршрута после `ifup`) · `path_vpn` · `path_vpn_nop2p` ·
`path_ai` · `ai_dns` · `youtube` · `torrent` · `diagnostic` · `doctor` · `device_modes` ·
`backup_share` · `self_update` · `admission_service`.

Версия модуля — это релиз, в котором он последний раз менялся (например `core 1.27.10`,
`youtube 1.22.5`, `doctor 1.30.7`). Набор выбирается при установке (`--list-modules`,
`--modules=`); снятый модуль остаётся видимым в панели со статусом «не выбран» и не
обновляется. Подробности — [docs/MODULES.md](docs/MODULES.md).

## Диагностика

Вкладка «Диагностика» (модуль `doctor`) отвечает на вопрос «почему этот сайт идёт не туда»
без консоли:

- проверки по каждому модулю, по роутеру, сети и путям — с вердиктом и строкой «что делать»;
- **маршрут домена**: DNS → группа MagiTrickle → правило mihomo → узел и страна выхода →
  живой HTTP-запрос → **связанные хосты** (редиректы, ссылки, формы, iframe, SAN
  сертификата), у каждого — свой путь и страна;
- каждый прогон пишется в свой лог (`/root/geomask-logs`), логи живут 7 дней.

Проверки только читают состояние: если что-то можно починить безопасно, инструмент
подскажет команду, но сам конфиги не переписывает. Подробности —
[docs/DIAGNOSTICS.md](docs/DIAGNOSTICS.md).

## Обновления

Роутер берёт релиз с GitHub и принимает его только если сходится всё: `GM_VERSION` внутри
файла равен тегу, а sha256 — digest ассета. Перед установкой делается полный
`sysupgrade -b`, сервисы не перезапускаются.

Публикация релиза — `tools/release.py` (`status`, `publish`, `verify --full`, `drift`):
он прогоняет тесты, ставит тег, создаёт релиз с ассетом `geomask.sh` и сверяет digest.
Порядок и контракт описаны в [docs/RELEASING.md](docs/RELEASING.md).

## Ограничения

- geomask не устанавливает прошивку, не настраивает WAN/PPPoE и не заменяет `mihomo`:
  он приводит существующий стек в рабочее состояние и объясняет расхождения.
- Любое изменение на роутере — только после свежего полного `sysupgrade -b`, сохранённого
  на ПК. Восстановление LuCI возвращает настройки, но не произвольный сервисный код.
- Правки конфига mihomo проверяются `mihomo -t` до применения; установщик не применяет
  конфиг, который не прошёл проверку.

## Разработка

```text
geomask.sh.in   шаблон установщика — редактируемый источник
assets/         бэкенд, rpcd, ACL, страница панели, sync/guard, диагностика
build.py        сборка: подстановка ассетов и версий
geomask.sh      собранный артефакт (в git; вручную не редактируется)
modules/        манифесты модулей и каталог modules/index.json
tools/          сборка каталога, RPC-генератор, релизы, экспорт списков
tests/          unit-тесты (python) и песочница (sh)
docs/           справки, release notes, исторические планы и SPEC
```

```sh
python build.py                     # собрать geomask.sh
python tools/build_module_index.py  # каталог модулей
python tools/check_build.py         # артефакт == сборка
python -m unittest discover -s tests -p 'test_*.py'
bash tests/run_tests.sh             # песочница
```

CI (`.github/workflows/ci.yml`) на каждый push проверяет сборку, RPC-манифест, синтаксис,
python-тесты и песочницу.

## Секреты и бэкапы

В репозитории нет подписочных ссылок, UUID, ключей и паролей — это проверяется тестами и
сканированием релизного артефакта. Полные конфиги и архивы бэкапов остаются на ПК; на
роутере допустима одна свежая копия (`/root/geomask-backups`), которую отдаёт read-only
SMB-шар `geomask-backups`.
