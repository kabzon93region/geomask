# geomask v1.7.1 — фикс гонки rpcd при пересстановке

**Дата:** 2026-10-23. **Тип:** багфикс (PATCH) к v1.7.0 (самообновление из панели).

## Что чинится

При `--reinstall` «удаление → установка» выполнялись **два `rpcd reload` подряд**
(после удаления файлов и после записи новых). procd мог склеить эти сигналы и потерять
второй — rpcd перечитывал файлы в момент, когда их ещё не было, и ubus-объект `geo-sync`
оставался незарегистрированным: шаг verify падал с `geo ubus: missing`, панель оставалась
без методов до ручного reload.

**Исправление:**
- `geomask_uninstall` в потоке пересстановки больше **не делает** reload (вызывается с
  `noreload`) — единственный reload остаётся в шаге установки;
- шаг установки после reload **проверяет регистрацию `geo-sync` и повторяет reload**
  (до 2 раз), пока объект не появится в ubus.

## Проверки

- Песочница: **52/52** (S1..S12, включая маркеры самообновления из v1.7.0);
- `check_build` + `sh -n` зелёные;
- На роутере: `--reinstall --yes` → `rc=0`, `verify: PASS`, `ubus call geo-sync upd_status`
  отвечает.

## Обновление

Панелью («Обновления» внизу → «Обновить до v1.7.1») или вручную:

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh --reinstall --yes
```
