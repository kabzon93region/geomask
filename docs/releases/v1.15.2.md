# geomask v1.15.2 — watchdog теперь видит «соединилось, но данные не идут»

## Какую слепую зону закрывает

До этой версии `geomask-ytwatch.sh` реагировал только на **ошибки диала** из лога mihomo
(`dial ... error: i/o timeout`). Если DPI убивает поток **после** успешного TCP-рукопожатия,
ядро ошибку не пишет вообще — и watchdog остаётся слепым. Именно так вёл себя роутер
31.10 во время 20-минутной загрузки видео на TV-приставке:

```
[TCP] ... --> rr7---sn-xguxaxjvh-bvwe.googlevideo.com:443 match Match using GLOBAL[DIRECT]   (×11)
ошибок диала: 0     авто-пинов: 0     ytvpn.yaml: payload: []
```

Соединение устанавливалось, данных не шло, пинить было нечего.

## Что добавлено

Второй источник сигнала — **API контроллера mihomo** (`GET /connections`, с Bearer). Ребро
считается зависшим, если одновременно:

- хост оканчивается на `googlevideo.com`;
- цепочка выхода — `DIRECT` (то, что уже уехало в AI/VPN, пинить бессмысленно);
- соединение живёт дольше `stall_min_age` секунд (по умолчанию 25);
- скачано меньше `stall_max_bytes` байт (по умолчанию 10000 — голое TLS-рукопожатие это ~2-4 КБ).

Хост должен попасться в `stall_threshold` подряд идущих срезах (по умолчанию 1; cron — каждые
5 минут). Дальше — обычный путь: правило `domain` в группу «GoogleVideo VPN» → синк →
`ytvpn.yaml` → `RULE-SET,ytvpn,VPN` до `ytdirect`. Ночной `--reset` отпускает пины и чистит
счётчики наблюдений, как и раньше.

Настройки в `/etc/geomask-ytwatch.conf`:

```
stall_min_age=25
stall_max_bytes=10000
stall_threshold=1
```

## Панель

В карточке «YouTube: рёбра googlevideo» появилась строка **«Зависшие рёбра»**: сколько хостов в
последнем срезе живут без данных, пороги срабатывания и список этих хостов. Это позволяет
увидеть проблему до того, как она станет пином, и отличить «DPI режет после handshake» от
«ребро недоступно совсем».

## Тесты

Новый `tests/test_ytwatch_stall.py` (11 проверок): разбор RFC3339 с долями секунд и `Z`,
положительный случай, «свежее соединение — не вешаемся», «трафик идёт — не вешаемся»,
нецепочка DIRECT игнорируется, чужие хосты игнорируются, пустые поля не роняют, конфигурируемость
порогов, счётчик повторных наблюдений, выдача в панель, очистка при `--reset`.
Классификатор вынесен в чистую функцию `is_stalled()`, поэтому тестируется без роутера.
Песочница: **186** проверок (S20 дополнен восемью), юнит-тесты: **27**.
