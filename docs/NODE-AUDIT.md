# Раздельные фильтры выхода VPN / VPN-noP2P / AI

## Полный цикл (состояние на 08.11.2026, вечер)

Три независимых набора разрешённых стран, три отдельные проверки и **отдельное применение** к трафику. Проверка никогда не переключает рабочий узел; применение затрагивает только выбранный путь.

- VPN: предложены NL,DE,FR,SE; VPN-noP2P: DE,PL; AI: US.
- Связь путь → группа → источник берётся из действующего mihomo config, не жёстко из sub/de5.
- Один runtime-аудит одновременно (ограниченные ресурсы роутера); соседний запуск возвращает busy, не притворяется запущенным.
- Факты относятся к конкретному сайту и времени. География входного сервера не заменяет выход к сервису.
- Новый аудит отделён от старого ночного сканера; его deny/ASN/name-фильтры и расписание не переписаны.
- Geomask автономен: Save, Check, Preview, Apply и ночное расписание не требуют ПК.

## Пользовательский цикл

1. **Сохранить настройки** — сохраняет разрешённые страны. Валидация ISO-2, flock, проверка ревизии, атомарная замена. Не применяет к трафику и не трогает соседние пути. No-op не пишет файл.
2. **Проверить путь** — фоновое задание: изолированный mihomo, свежая выдача подписки, по одному проверяемому узлу. Прогресс, отмена, восстановление после обновления страницы.
3. **Предпросмотр** — точный состав будущего пула: какие узлы добавятся, какие удалятся, что будет с текущим узлом.
4. **Применить фильтр** — подтверждённая транзакция: кандидат проверяется `mihomo -t`, изолированный прогон, атомарная замена, reload, сверка рабочего пула.
5. **Отозвать фильтр** — удаляет исключённые узлы из группы.
6. **История** — события Save / Check / Preview / Apply / Revoke / Schedule.

## Хранение

| Путь | Назначение |
|---|---|
| `/etc/geomask/node-audit.json` | Canonical store схемы v2: страны, path_revision, source_binding, schedule, applied |
| `/etc/geomask/node-audit/events.jsonl` | Append-only журнал, ротация: 20 событий/путь, 200 всего, 2 МиБ |
| `/etc/geomask/node-audit/reports/` | Неизменяемые отчёты заданий, 20/путь, 100 всего, 10 МиБ |
| `/etc/geomask/node-audit/pools/` | Неизменяемые проверенные пулы поколений (0600) |
| `/tmp/geomask-node-audit/<path>.json` | Указатель на последний отчёт (теряется при перезагрузке) |

Настройки, журнал и отчёты **сохраняются при удалении** — это политика владельца и доказательства.

## Что проверяется

Изолированный mihomo с loopback listener и отдельным controller, статический список свежезагруженных узлов, фиксированный тестируемый узел. Production-группы не переключаются. TLS проверяется, curl-конфиг пользователя отключён. Подписки HTTPS; перенаправления не принимаются, заголовки авторизации не пересылаются на другой endpoint. Неподдержанный формат/слишком малая выдача/ошибка загрузки — ошибка, не пустой успешный список.

- VPN/VPN-noP2P: Cloudflare trace → наблюдаемые ip/loc/colo.
- AI: Cloudflare и ChatGPT раздельно. Для Google запрос к самому сервису подтверждает доступность; HTTP 204 не доказывает страну, поэтому до достоверного геопризнака Google = UNKNOWN и общий допуск AI не пройден.
- `www.google.com/cdn-cgi/trace` возвращает 404. Google Search может показывать местоположение через «From your internet address» (официальная [справка](https://support.google.com/websearch/answer/179386?hl=en)), но чистая браузерная проверка 08.11 встретила антибот-страницу. Исследование вариантов — [RESEARCH-GOOGLE-GEO](RESEARCH-GOOGLE-GEO-2026-11-08.md).
- SOCKS5h использует удалённое разрешение имени. Это не подтверждение пути реального клиента с локальными hosts.

## Применение: что именно меняется

`geomask-apply.py` компилирует пул только из узлов со статусом `eligible` для выбранного пути, затем в контролируемой группе заменяет список proxies. Остальные группы, правила и listeners не затрагиваются.

- Пустой пул или все UNKNOWN — применение отклоняется, DIRECT и другие подписки не подставляются.
- Предпросмотр связан с точной ревизией пути и задания; устаревший отклоняется.
- Срок годности применённого пула — 24 часа; по истечении статус `expired`, требуется повторное применение.
- Отзыв удаляет из группы узлы, ставшие `excluded`/`unknown`.

## Транзакции конфигурации

`geomask-config-tx.py` — единственный владелец записи mihomo-конфига:

- постоянный flock, проверка ожидаемой ревизии, staged-файлы вне критического участка;
- `mihomo -t` на кандидате, изолированный прогон со всеми listeners на свободных портах;
- независимый journal до первой мутации, восстановление после перезагрузки;
- при любом сбое — откат предобразов и сверка режима/хешей; неподтверждённое восстановление даёт `needs_recovery`, не SUCCESS;
- watchdog не восстанавливает предобраз поверх более нового успешного commit.

`geomask-config-owner.py` — реестр владения группами (`slot`, `scanner`, `audit`, `manual`), чтобы конкурирующие writers не перезаписывали чужой пул.

## Расписание

По каждому пути: `enabled`, `time` (HH:MM), `mode` = `check-only` | `check-and-apply`. По умолчанию — выключено; миграция ставит `check-only`, автоприменение требует явного включения владельцем.

## Карта интеграции

- `tools/geo-rpc.json` → `tools/gen-geo-rpc.py` → declarations LuCI, rpcd list/call, ACL, dispatcher backend.
- `assets/geo-sync-page.js` — карточки, прогресс, предпросмотр, применение, отзыв, история, расписание.
- `assets/geo-sync` проверяет сырой JSON до jshn через `validate-rpc`.
- `assets/geo-backend.sh` — диспетчер команд к модулям.
- `build.py` + `geomask.sh.in::step2_apply` встраивают семь модулей в `/usr/lib/geomask/`; `step2_check` их проверяет, `geomask_uninstall` удаляет только код.

## Состояния и ограничения

`eligible` — все обязательные сервисные факты соответствуют фильтру; `excluded` — подтверждённая страна вне списка; `unknown` — доказательств недостаточно. `complete` означает завершение измерения, не прохождение всех узлов. `stale` — исходный конфиг/настройки изменились. Внешняя подписка может измениться по тому же URL; результат содержит digest выдачи и время, не гарантию её неизменности.

Приватный тестовый каталог удаляется при штатном завершении и независимым ограниченным watchdog; PID проверяется по времени старта и командной строке перед сигналом. Общий бюджет задания ограничен. Никакие fallback/DIRECT или новые страны автоматически не включаются.

## Известный незакрытый gate

Достоверное автоматическое геоизмерение Google отсутствует. AI-применение честно блокируется по `UNKNOWN`, пока владелец не утвердит отдельный подход (см. исследование). VPN и VPN-noP2P этим не заблокированы.
