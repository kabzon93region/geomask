# geomask v1.7.3 — шаблон догоняет боевой конфиг (5228, IPv6 off, QUIC-REJECT)

**Дата:** 2026-10-25. **Тип:** фиксы/безопасность (PATCH) к v1.7.2.

## Что меняется

- **Шаблон mihomo (свежая установка) теперь равен боевому конфигу:**
  - `sniffer.sniff.TLS.ports: [443, 8443, 5228]` — служебный канал Google Push
    (`mtalk.google.com`, 5228) распознаётся по домену и уходит через AI-подписку
    (**B-017**: раньше домен не читался → DIRECT с домашним IP → Google видел РФ);
  - `ipv6: false` — IPv6 отключён и в mihomo (отключение IPv6 на роутере 25.10);
  - правила `REJECT` для QUIC видеохостов (googlevideo/youtube/youtu.be → форс TCP,
    **B-016** тротлинг QUIC-видео), блок `DST-PORT → VPN` и direct-fallback SNI —
    всё это было только в живом конфиге, теперь пишется шаблоном.
- **`--check` получил новые проверки:** sniffer 5228 (падение чека при отсутствии),
  `ipv6: false` и QUIC-REJECT (предупреждение) — регресс виден сразу.
- **`--reinstall` — текст предупреждения приведён к факту:** существующий
  2-подписочный конфиг сохраняется (патчатся только ссылки подписок), шаблон
  пишется лишь при отсутствии конфига/маркеров (старый — в бэкапе).

## Обновление

Панелью: «Гео-маскировка и AI» → внизу «Обновления» → «Проверить ещё раз» →
«Обновить до 1.7.3». Для работающего роутера с текущим конфигом обновление
функционально ничего не меняет (все фиксы уже применены вживую) — актуально
для чистых установок и как основа будущих `--reinstall`.
