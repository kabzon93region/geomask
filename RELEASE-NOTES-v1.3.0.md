## geomask v1.3.0

Реестр подписок и AI-маршрутизация устройств в панели «Гео-маскировка и AI».

### Что нового

- **Реестр подписок** (карточка «Подписки» в LuCI): добавление ссылок с именем, список с назначением (VPN/AI), кнопки «→ VPN» и «→ AI» — переключение провайдеров `sub`/`de5` mihomo через API без перезапуска; удаление подписок. Хранение: `/etc/geomask-subs.list`.
- **AI-устройства**: новый режим устройства «Через AI-подписку (весь трафик)» — трафик указанного устройства целиком уходит через AI-подписку. При первом добавлении автоматически создаётся второй инстанс hev-socks5-tunnel (TUN `AI` 198.19.0.1, socks 7891), интерфейс и firewall-зона; рабочий VPN-туннель не перезапускается.
- **Слушатель mihomo** `listeners.ai-devices` (mixed, 127.0.0.1:7891, proxy AI) добавляется в конфиг с бэкапом и проверкой `mihomo -t`. Активируется при старте mihomo — до этого панель показывает предупреждение с командой.
- Новые ubus-методы: `subs_list`, `sub_add`, `sub_del`, `ai_sub_use`, `vpn_sub_use`; в статусе — `n_ai`, `ai_tun`, `ai_listener`, активные подписки.

### Установка

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh
```
