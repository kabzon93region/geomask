# geomask v1.5.8 — AI-устройства без «перемешки»; STUN через VPN; сохранение x-hwid

## Главное

- **AI-устройства: устойчивые приоритеты `ip rule`.**
  Per-device правила (режим «весь трафик через AI»), ICMP-bypass и AI-DNS переведены в низкий
  диапазон приоритетов `20000/20001/20002`. Раньше они стояли на `32610/32611/32620` и периодически
  оказывались **ниже** базы fwmark-правил magitrickle — а та динамическая и смещается вниз по мере
  роста числа групп (наблюдалось `32645…` → `32589…32609` → `32558…32578`). Из-за этого помеченный
  трафик AI-устройства уходил в основной туннель: сайт показывал домашний IP вместо AI, либо трафик
  шёл «вперемешку».
  Теперь любые per-device правила гарантированно выше magitrickle.
  Затронуты `assets/99-default-vpn-route`, `assets/geo-backend.sh`, `geomask.sh.in`.

- **STUN (WebRTC) через VPN.**
  В правила mihomo добавлены:
  ```yaml
  - AND,((NETWORK,udp),(DST-PORT,3478)),VPN
  - AND,((NETWORK,udp),(DST-PORT,19302)),VPN
  ```
  Сайты проверки IP больше не «видят» реальный адрес через WebRTC; звонки при этом не ломаются
  (STUN не блокируется, а направляется через туннель).

- **Сохранение `x-hwid` при переключении подписок.**
  Кнопки «→ VPN»/«→ AI» в панели теперь переносят заголовок `x-hwid` в целевой провайдер, чтобы
  не потерять HWID-привязку ключа.

## Обновление

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@v1.5.8/geomask.sh' && sh /tmp/geomask.sh
```

или

```sh
opkg install https://github.com/kabzon93region/geomask/releases/download/v1.5.8/geomask.sh
```

## Примечания

- После обновления при необходимости перепримените маршрутизацию:
  `ACTION=ifup /etc/hotplug.d/iface/99-default-vpn-route` (при следующем `ifup` — автоматически).
- Проверка: `ip rule show` — правила AI/bypass-устройств должны быть на `20000`, magitrickle — выше
  по номеру.
- Release notes перенесены в `docs/releases/`.
