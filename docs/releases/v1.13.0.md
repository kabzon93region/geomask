# geomask v1.13.0 — шаблоны списков MagiTrickle: сид и восстановление

## Главное

- **geomask владеет доменными списками.** Снимок всех групп MagiTrickle (To VPN / To Not VPN /
  Google+AI to DE / Geoblock / Block / Youtube и др. — 25 групп, ~3300 правил) теперь хранится в
  репозитории (`assets/magitrickle-groups.yaml` + `templates/lists.meta.json`) и укладывается на
  роутер (`/etc/geomask/lists/`). Раньше списки жили только runtime и терялись при сбое конфига
  (инцидент B-018). Секретов в шаблонах нет — проверено и закреплено тестом.

- **Безопасный сид.** Новый `geomask-seed-lists.py` сшивает блок `groups:` в живой конфиг,
  сохраняя хостовые `app:`-настройки и `subscriptions:`, с бэкапом `config.yaml.bak_geomask_<ts>`.
  Авто-сид (шаг 5) срабатывает **только если MagiTrickle пуст** — runtime-правки владельца не затираются.

- **Явное восстановление:** `sh geomask.sh --seed-lists` перезаписывает текущие группы шаблоном
  (magitrickled перезапускается на секунды, mihomo перечитывает конфиг через API — VPN не рвётся).
  В панели — новая карточка «Списки и шаблоны» (вкладка «Списки и синк»): версия шаблона, число
  групп/правил «в шаблоне vs сейчас», кнопка «Восстановить из шаблона» с подтверждением.

## Файлы

- `assets/magitrickle-groups.yaml` (шаблон), `assets/geomask-seed-lists.py` (сид),
  `templates/lists.meta.json` (метаданные), `geomask.sh.in` (write_lists_assets/seed_lists/--seed-lists),
  `assets/geo-backend.sh` (`lists_get`/`lists_seed`), `assets/geo-sync-page.js` (карточка),
  `docs/LISTS.md`, `tests/run_tests.sh` (сценарий S17).

## Обновление

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@v1.13.0/geomask.sh' && sh /tmp/geomask.sh
```

или через панель: «Обновление» → установить, затем «Списки и синк» → карточка «Шаблоны списков».

## Примечания

- Обычная установка/`--auto` списки НЕ перезаписывает (авто-сид откладывается, пока в MagiTrickle
  есть группы). Чтобы вернуть конфиг к снимку — только явный `--seed-lists` или кнопка.
- Тонкая правка отдельных доменов по-прежнему в панели MagiTrickle (`:8080`); geomask-шаблон —
  это именно резервная точка восстановления.
- Тесты: `tests/run_tests.sh` → 107 проверок (добавлен S17: wiring + скан секретов + контракт сида).
