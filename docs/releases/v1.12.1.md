# v1.12.1 — фиксы контролов вкладки «Узлы/Списки»

- cmd_stack: флаг nodescan_enabled попадал в значение счётчика exclude (коллизия переменной _ne) — переименован.
- syncd_set: проверка результата на цепочке &&/|| давала ложный «ok:false» при успешном включении — переписано на if.
- nodes_get/enabled: распознавание cron-строки точным совпадением конца строки (не подстрокой).
- sync_set: тег без двойного '#'; удаление строки синка по точному пути скрипта.
- nodes_set: журнал-строка о сохранении настроек возвращена.
