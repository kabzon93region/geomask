# geomask v1.19.0 — синк с запретом и запрет на «портовые» правила в запрещённом слоте

## 1. Направление A: туннелируемые домены → в исключения запрета

`sync_mtrickle_mihomo.sh` теперь ведёт в `/opt/zapret/ipset/zapret-hosts-user-exclude.txt`
**управляемый блок** между метками `# >>> geomask sync: tunneled domains >>>` / `# <<< ... <<<`.

Логика: в исключение попадают домены, которые уходят **через туннель** — `mtrickle` (домены),
`ai`, `ytvpn`. Смысл не в экономии: запрет в hostlist-режиме правит DNS-ответы и подставляет
fake-пакеты по известным доменам, а для туннелируемого трафика это только шум — на WAN запрет
видит зашифрованный хоп до прокси, а не исходный SNI.

Два важных ограничения:

* **домены, которые mihomo сам отправляет DIRECT, из-под запрета не вычёркиваются** — они
  вычитаются из множества по явному списку правил `DOMAIN-SUFFIX,...,DIRECT` в конфиге. Иначе
  мы бы сняли DPI с того трафика, который как раз и идёт в открытую (rutracker/piratebay закреплены
  DIRECT выше всех правил);
* **весь остальной содержимое файла сохраняется как есть**, включая первую строку `# nochange` —
  блок переписывается вокруг неё, файл не перестаёт быть «нашим».

**Направление B не автоматизировано сознательно.** Домены из force-списка запрета (123 из 126 не
состоят в прямых группах) нельзя молча положить в `To Not VPN`: они пересекутся с курируемыми
группами Mihomo и создадут ровно те конфликты, которые мы сегодня чинили (у `ggsel.com` был
одновременно «в туннель» и «напрямую»). Такие пересечения — решение человека, не скрипта.
Обратно (исключения запрета → в MagiTrickle) не копируется никогда: там русские сайты.

## 2. Инвариант: в запрещённый слот не ведут правила по порту, протоколу или IP

Правило `(NETWORK,udp),(DST-PORT,3478)` — это **совпадение по порту**, а не проверка, что внутри
STUN. Торрент-клиенту достаточно выбрать этот порт, и трафик поедет по правилу; шифрование для
этого не нужно. Порт 3478 вообще является портом TURN — универсального ретранслятора.

`--check` теперь считает ошибкой любое правило с `SRC-PORT|DST-PORT|IP-CIDR|NETWORK`, ведущее в
`VPN-noP2P`, если рядом существует отдельная терпимая полоса `VPN`. На машине с одним туннелем
проверка молчит: там портовым правилам просто некуда уйти, и требовать этого нельзя.
