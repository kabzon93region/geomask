# geomask v1.5.7 — AI-DNS: утечка DNS устранена (по умолчанию)

## Что было
Веб-трафик AI-устройств (режим «Через AI») шёл через AI-туннель, а DNS
резолвился самим роутером и уходил с реального IP провайдера. Geo-чекеры
видели «страница из страны AI-ноды, DNS из страны провайдера» → флаг VPN.

## Что сделано (новый шаг мастера `aidns`, включён по умолчанию)
```
 aidns    AI-DNS: DNS AI-устройств через их же туннель — нет утечки DNS (ставится по умолчанию)
```

Цепочка:
```
DNS AI-устройства (любой адрес, порт 53)
  --nft DNAT (приоритет -110, выигрывает у ВСЕХ перехватов: magitrickle MT_DNSOR,
    adblock-fast и https-dns-proxy force_dns)-->
  192.168.0.53:5353 (второй dnsmasq)
  --> 127.0.0.1:5055 (второй DoH-воркер, запущен от пользователя dnsai)
  --nft метка 0x64 по uid сокета--> ip rule fwmark 0x64 table 101 --> dev AI
```
- RU-домены (yandex/vk/playstation/sberbank...) по-прежнему резолвятся как раньше.
- Панель «Гео-маскировка и AI» показывает статус: «DNS AI-устройств: через AI-туннель (утечки нет)».
- Отключение: `touch /etc/geomask-aidns.off` (шаг становится no-op).
- При добавлении/удалении AI-устройств список DNAT пересинхронизируется автоматически.
- Персист после ребута: nft-файл в `/usr/share/nftables.d/ruleset-post/`,
  ip rule — в hotplug `99-default-vpn-route`.

## Проверено на роутере
- Все 7 шагов мастера: ALL GOOD (`--check` → pass=7).
- `ip route get 1.1.1.1 mark 0x64` → `dev AI table 101`.
- Реальные DNS-запросы через AI-цепь (example/google/ya.ru) резолвятся; счётчики
  AI-TUN растут на каждый запрос — трафик реально идёт через туннель.
- Основной DNS (остальные устройства) не затронут; adblock работает.
- Add/delete устройства: DNAT-список обновляется корректно.
- Sandbox: 38/38 PASS.
