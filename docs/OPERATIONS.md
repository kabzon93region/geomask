# Режимы и эксплуатация

## Режимы запуска

| Режим | Команда | Что делает |
|---|---|---|
| Интерактив | `sh geomask.sh` | Меню: сводка статусов + диагностика/мастер/пересстановка |
| Пересстановка | `sh geomask.sh --reinstall` | Удалить → установить → настроить; mihomo **не** перезапускается |
| Полный авто | `sh geomask.sh --auto` | Все шаги без вопросов; стоп при verify-FAIL |
| Только проверка | `sh geomask.sh --check` | Read-only отчёт по всем шагам |
| Один шаг | `sh geomask.sh --step N` | Только шаг N (1..7) |
| Без вопросов | `+ --yes` | Не спрашивать подтверждений |
| С рестартом | `+ --restart` | Разрешить перезапуск mihomo (обрыв ~3с). Игнорируется при `/root/.geomask-norestart` |
| С подписками | `+ --vpn-url URL --ai-url URL` | Задать URL подписок |
| Бэкап | `sh geomask.sh --backup` | Полный бэкап (`sysupgrade -b`) в `/tmp/geomask-backups/` (tmpfs — забрать на ПК, пропадет после перезагрузки) |

## Шаги

1. **env** — окружение.
2. **geo** — гео-оверлей LuCI.
3. **subs** — конфиг mihomo (+`mihomo -t`).
4. **aidns** — AI-DNS без утечки.
5. **sync** — sync magitrickle → mihomo + cron + hotplug-роутинг.
6. **services** — старт только упавших сервисов.
7. **verify** — E2E-проверки.

## Обновление из панели (самообновление, v1.7.0+)

Внизу страницы «Гео-маскировка и AI» — блок **«Обновления»**: версии geomask (ядро / админка /
guard) и справочно стек. Проверка — при открытии страницы (кэш 1 ч) и кнопкой «Проверить ещё раз»
(GitHub `releases/latest`, фолбэк — raw master).

Кнопка **«Обновить до vX»** выполняется отсоединённым процессом:
`полный бэкап sysupgrade -b → скачивание релиза (jsDelivr, fallback GitHub) → sh -n + версия +
sha256 = digest релиза → sh new --reinstall --yes (файлы модулей/панели, без рестартов сервисов)
→ rpcd reload`. Статус — `/tmp/geomask-upd/status.json`, панель опрашивает его каждые 2 с и по
«Готово» предлагает обновить страницу (Ctrl+F5).

v1.8.0: каждый шаг — отдельная строка в тёмной консоли блока (источник —
`/tmp/geomask-upd/steps.log`, поле `lines` в `upd_status`) и дубль в `/root/geo-sync.log`
(`GEOMASK-UPD [...]`). Там же виден **путь, размер и md5 бэкапа**, созданного перед обновлением
(`/tmp/router-backup-<ts>.tar.gz`, tmpfs — **исчезает после перезагрузки**): забрать на ПК —
`powershell -File fetch_backup.ps1` (сам находит свежий архив, сверяет md5, кладёт в
`Y:\openwrt\backup\`, копию на роутере удаляет). После успешного применения кэш `check.json`
сбрасывается — версии на странице сразу показываются новые (фикс «после обновления показывает
старую версию» из кэша 1 ч).

Проверить/починить вручную:

```sh
cat /tmp/geomask-upd/status.json                 # фаза/сообщение
tail -40 /tmp/geomask-upd/steps.log              # пошаговая консоль обновления
cat /tmp/geomask-upd/backup.info                 # бэкап: файл + md5
tail -20 /tmp/geomask-upd/upd.log                # вывод установки
sh /usr/bin/geo-backend.sh upd_check force       # перепроверить версии минуя кэш
```

Ограничение: первая установка новой панели — обычным способом (синк/установщик): у старой панели
блока обновлений нет. Обновляться кнопкой она умеет, будучи уже ≥1.7.0.

## Безопасность и бэкапы

- Никаких `reboot`, не трогаем `network`/`pppoe`.
- Перед каждой записью файла — копия `.bak_geomask_<timestamp>`.
- Полный бэкап: `sh geomask.sh --backup` → `/tmp/geomask-backups/router-backup-<ts>.tar.gz`
  (tmpfs, LuCI-совместимый архив; **не хранится на overlay** — c v1.8.1 старые копии в
  `/root/geomask-backups/` автоматически удаляются, до этого они вложенно раздували каждый
  следующий sysupgrade-архив). Забор на ПК: `fetch_backup.ps1` (md5-сверка + удаление копии
  на роутере), восстановление — LuCI → Backup / Flash Firmware → Restore.
- Перед рестартом mihomo (шаг 3 с `--restart`): авто-бэкап → trial-run копии конфига в
  `/tmp/gm-trial-*` на портах 17890/17901/19090 → рестарт → проверка pid + API; при провале —
  **автоматический откат**.
- Pin-блокировка рестартов: `/root/.geomask-norestart`.
- Подписки применяются через API без рестарта; полный рестарт — только по `--restart`.

## Проверка после изменений на роутере

```sh
sh /tmp/geomask.sh --check            # сводка по всем шагам
ip rule show                          # приоритеты 19900/19901/19902 выше magitrickle
netstat -tlnp | grep -E '7890|7891'   # слушатели mihomo
pidof mihomo magitrickled             # живые сервисы
```
