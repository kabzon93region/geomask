# geomask v1.5.3 — работающая кнопка «Что видит Google?»

## Исправлено
- **Кнопка «Что видит Google?» снова отвечает.** Старая проверка тянула
  HTML главной google.com через смешанный порт 7890 и вытаскивала страну
  регуляркой по `class="O3yKUb"`. Google отдаёт 302-редирект и поменял
  разметку — проверка всегда возвращала пусто («Google видит: (нет ответа)»).
  Теперь проверка спрашивает страну выхода у сервиса geo-IP **через
  AI-слушатель mihomo (127.0.0.1:7891, `proxy: AI`)** — это ровно тот выход,
  которым идёт Google-трафик по правилам ai.yaml. Ответ — код страны (`US`,
  `DE` и т.п.), без редиректов и парсинга HTML.
- Убраны жёстко зашитые «Германия» из подписей панели: AI-подписка
  переключаемая (сейчас USA), поэтому подписи стали нейтральными —
  «AI-подписка», фактическую страну выхода показывают блоки статуса.

## Проверено на роутере
- `ubus call geo-sync google` → `{"google":"US","ai_node":"🇺🇸 USA C4 …"}` —
  реальная страна AI-выхода совпадает с выбранной подпиской.
- `sh -n` синтаксис бэкенда — OK; sandbox 37/37.
