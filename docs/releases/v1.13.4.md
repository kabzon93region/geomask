# geomask v1.13.4 — согласованный релиз для обновления

Исправлена публикация: у v1.13.3 git-тег ссылался на промежуточный коммит, а release-артефакт был заменён более новым файлом. Поэтому загрузка по тегу не совпадала с SHA-256 из GitHub API. Проверка правильно остановила установку до применения изменений.

v1.13.4 публикуется новым неизменяемым тегом: собранный установщик в коммите и release-артефакт должны совпадать побайтно. Проверка SHA-256 сохранена.

Включает исправления регистрации lists_get/lists_seed и aidns в rpcd, разрешения ACL и генерацию ytvpn из группы MagiTrickle «GoogleVideo VPN».

Перед публикацией: 120 проверок песочницы успешно (предыдущий прогон). Реальное воспроизведение YouTube этим релизом не проверено.
