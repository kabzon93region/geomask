# geomask v1.5.2 — реальное переключение подписок (AI/VPN)

## Исправлено (критично)
- **Смена подписки в панели наконец реально применяется.** Раньше бэкенд после правки
  конфига вызывал `PUT /providers/proxies/<name>` с неверным телом
  (`vehicle_type` вместо `vehicleType`, `http` вместо `HTTP`) — API отвечал 204,
  но mihomo продолжал держать старые ноды. Вид в панели менялся, трафик — нет.
  Теперь используется рабочий механизм: `PUT /configs` с телом
  `{"path":"/etc/mihomo/config.yaml"}` — mihomo перечитывает конфиг и
  перезагружает подписку (провайдер `sub`/`de5`) **без перезапуска процесса**.
- После применения добавлена **проверка результата**: замеряем число нод у
  провайдера через API; если подписка отдала пусто (битая/пустая ссылка) —
  возвращается предупреждение `warn`, чтобы в панели было видно, что произошло,
  вместо молчаливой «успешной» смены.
- Та же правка в установщике (`api_refresh_provider`) — в `geomask.sh`
  и в шаблоне `geomask.sh.in`.
- README: уточнено описание механизма применения подписок.

## Проверено на роутере
- Переключение AI в обе стороны (Германия ↔ USA): после каждого шага группа `AI`
  реально показывает ноды выбранной подписки (🇩🇪 Германия 5 🎮 ↔ 🇺🇸 USA C4 🚀).
- Финальная проверка на текущем выборе (AI = USA): `proxies/AI` → `USA C4`,
  выход через AI-путь работает.
- Регрессии: сервисы `mihomo`, `hev-socks5-tunnel` (оба туннеля `main` и `ai`),
  `dnsmasq`, `magitrickled`, `uhttpd`, `rpcd` — работают; таблицы/маршруты/tun
  на месте; интернет и DNS в норме.
- Sandbox: **37/37 PASS**.
