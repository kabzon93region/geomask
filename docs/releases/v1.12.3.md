# v1.12.3 — честные цвета в консоли обновлений и журнале

Жёлтый цвет больше НЕ означает фазы процесса: шаги (queued/backup/download/validate/apply) — серые, жёлтый оставлен только настоящим предупреждениям (warn), зелёный - завершению (done/обновлено/SYNC changed), красный - ошибкам. Тот же принцип применён к журналу на вкладке Обзор (раньше был одноцветным полотном).
