# geomask v1.13.5 — авторизация контроллера mihomo

Исправлена причина ложного отказа установки: итоговая проверка и обновление провайдеров обращались к защищённому API mihomo без Bearer-токена и принимали HTTP 401 за отсутствие групп VPN/AI.

Секрет читается из локального конфига роутера, не выводится в журнал и не включается в шаблоны. Авторизация также применяется при перечитывании списков синхронизатором. Проверки контрольной суммы установщика сохранены.

Маршруты и пользовательские списки этим исправлением не меняются.
