## geomask v1.2.0

Убрана интеграция с сторонней панелью; переработано главное меню.

### Удалено

- Шаг «panel»: установка/проверка сторонней панели Zapret-Manager больше не выполняется и не упоминается — ни в скрипте, ни в меню, ни в сводке. Шагов стало 6: env → geo → subs → sync → services → verify.

### Главное меню

Теперь три пункта:

1. **Быстрая диагностика** — только чтение, отчёт по всем шагам.
2. **Пошаговый мастер** — список всех шагов с их статусом («выполнено» / «требует внимания»); можно запустить любой шаг отдельно, после выполнения список статусов обновляется.
3. **f) Удалить → установить → настроить geomask** — полный пайплайн как раньше.

### Установка

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh
```
