## geomask v1.1.0

Интерактивное главное меню со сводкой статусов, пересстановка в один пункт и управление AI-подпиской из LuCI.

### Что нового

- **Главное меню как в Zapret-Manager**: перед каждым показом — цветная сводка (роутер, Zapret/Mihomo/MagiTrickle/hev/dnsmasq, узлы VPN и AI, Geo LuCI, число sync-правил, pin-статус рестартов); циклическое меню действий.
- **Пункт «Удалить → установить → настроить geomask»** (`f` в меню или `--reinstall`): сносит гео-оверлей/sync/cron, переустанавливает их, спрашивает обе подписки (Enter = оставить текущие), перезаписывает mihomo-конфиг с бэкапом и проверкой `mihomo -t`.
- **Без обрыва VPN**: подписки применяются через локальный API mihomo (`PUT /providers/proxies/sub|de5`) — без перезапуска процесса.
- **AI-подписка в LuCI**: на странице «Гео-маскировка и AI» появилась карточка «Подписка AI (de5)» — поле со ссылкой и кнопка «Применить» (новые ubus-методы `ai_sub_get`/`ai_sub_set`).
- Исправлено: извлечение URL провайдеров из конфига брало health-check URL вместо de5.

### Установка на роутере

```sh
sh <(wget -qO - 'https://raw.githubusercontent.com/kabzon93region/geomask/master/geomask.sh')
```

### Режимы

- `sh geomask.sh` — главное меню
- `sh geomask.sh --reinstall` — удалить → установить → настроить
- `--auto`, `--check`, `--step N`, `--yes`, `--restart`, `--vpn-url/--ai-url` — как раньше

### Безопасность

Без reboot, работающие сервисы не перезапускаются, бэкапы перед записью, `mihomo -t` перед установкой конфига, pin `/root/.geomask-norestart` блокирует `--restart`. Песочница: 25/25 PASS.
