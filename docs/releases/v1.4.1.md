## geomask v1.4.1

Патч переконфигурации: существующий конфиг mihomo больше не перезаписывается шаблоном.

### Исправлено

- **Сохранение кастомного конфига**: если в `/etc/mihomo/config.yaml` уже есть
  две подписки (`sub` + `de5`) и группы `VPN`/`AI`, шаг subs теперь **не
  перезаписывает файл шаблоном** (ранее терялись кастомные правила —
  DST-PORT, rutracker/thepiratebay, sniffer-настройки). Вместо этого:
  по необходимости точечно меняются URL провайдеров и добавляется только
  блок `listeners`.
- **trial-run**: абсолютные пути ruleset в копии конфига переписываются на
  локальные (иначе пробный запуск упирался в SAFE_PATHS mihomo и ложность
  давал сбой).
- Проверка шага subs теперь также требует наличия `listeners (ai-devices)`.

### Безопасность (как в v1.4.0)

`--backup`, trial-run на портах 17890/17901/19090 перед любым рестартом
mihomo, верификация pid+API, автоматический откат.

### Установка

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh
```
