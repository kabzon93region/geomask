# v1.12.0 — панель по вкладкам + полный контроль автоматизации

## Визуал
Вкладки как у Zapret-Manager: **Обзор · Устройства · Подписки · Списки и синк · Узлы подписки ·
Бэкапы · Обновление · Настройки**. Последняя вкладка запоминается между входами (localStorage).

## Новый контроль (rpcd-методы + backend команды, всё валидируется)
- **Аудит узлов** (вкладка «Узлы подписки»): вкл/выкл ночного скана, время запуска (HH:MM),
  правила bad_countries/bad_asns/базовый фильтр/имя провайдера — просмотр и запись в
  `/etc/geomask-nodes.conf`, список заблокированных узлов, последние строки журнала,
  кнопка «Проверить сейчас». Бэкенд: `nodes_get`/`nodes_set`.
- **Автоматизация** (вкладка «Списки и синк»): вкл/выкл событийного сторожа (`syncd_set`),
  интервал cron-страховки синка 1/2/3/5/10/15/30 мин (`sync_set`).
- **Настройки**: пин «не рестартить mihomo» — снять/поставить кнопкой (`pin_set`), ссылки на
  MagiTrickle/Zapret-DPI/лендинг/LuCI, версия панели.
- Карточка стека показывает новые флаги (syncd_enabled, sync_interval, nodescan_enabled).

## Безопасность правок
Все значения проверяются на формат: время, ISO-страны, ASN-номера, запрет кавычек в фильтре;
crontab перезаписывается атомарно из временного файла; pinger watchdog не удаляет cron-страховку.
