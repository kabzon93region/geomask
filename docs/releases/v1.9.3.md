# v1.9.3 — перечисление секций uci: @share[N] и дедупликация

Детект-дефект v1.9.1/1.9.2: regex секций допускал только `A-Za-z0-9_`, а `uci show` для
безымянных секций печатает `ksmbd.@share[N]=share` (@,[,] не проходили) → шар.geomask
никогда не «находил», и каждый деплой создавал дубль секции, а прежняя секция с кавычками
`'1'` оставалась в ksmbd.conf. Теперь: обобщённый паттерн `[^=]*`, повторные прогоны
нормализуют первую секцию (yes/no) и удаляют дубли; пустые секции чистятся как раньше.

Тест S13+: паттерн перечисления + строка дедупликации. 67 проверок.
