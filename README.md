Надстройка над OpenWrt, которая собирает и держит в порядке стек маршрутизации: **mihomo**
(группы `VPN`, `VPN-noP2P`, `AI`), **MagiTrickle** (доменные группы → метки nftables →
туннели), **hev-socks5-tunnel** (TUN → SOCKS), **zapret** (обход DPI) и панель LuCI
«Гео-маскировка и AI» с центром диагностики.

## Технические характеристики

| | |
|---|---|
| Языки | установщик — **POSIX `sh`** (busybox ash), модули — **Python 3.7+**, панель — **JavaScript ES5** (LuCI view) |
| Платформа | **OpenWrt 24.10+** (`opkg`) и **25.x** (`apk`); целевое железо — **MediaTek Filogic / aarch64** (wwGate AX3000) |
| Модули | **15** частей, у каждой своя версия и отдельное обновление ([MODULES](docs/MODULES.md)) |
| Панель | LuCI, **9 вкладок**; RPC через `ubus` (`geo-sync`), ACL и меню в комплекте |
| Зависимости | `mihomo`, `magitrickle` — до установки; `python3`, `curl`, `https-dns-proxy` — ставит сам |
| Тесты | **534** unit-теста и **438** проверок песочницы, гоняются в CI на каждый push |
| Обновления | релиз с GitHub, сверка `GM_VERSION` = тег и sha256 = digest ассета; бэкап перед установкой |
| Лицензия | MIT |

Другие устройства не запрещены, но и не обещаны: установщик проверяет окружение и говорит,
чего не хватает, вместо того чтобы делать вид, что всё хорошо.

## Что нужно до установки

| | |
|---|---|
| OpenWrt | с `apk` (25.x) или `opkg` (24.x и старше) |
| терминал | `luci-app-ttyd` — ставится в шаге 1 ниже, если его ещё нет |
| обязательно | `mihomo` и `magitrickle` уже установлены — geomask настраивает их, а не заменяет |
| поставит сам | `python3`, `python3-yaml`, `curl`, `https-dns-proxy` (для AI-DNS) — через `apk`/`opkg` |
| по желанию | `zapret`, `hev-socks5-tunnel`, `tg-ws-proxy` — если нужны соответствующие пути |

`mihomo` и `magitrickle` в официальных фидах OpenWrt отсутствуют, поэтому установщик не
пытается ставить их сам: на шаге 1 он прямо говорит, что это надстройка и что поставить
сначала. Всё остальное, что есть в фидах, ставится автоматически.

## Установка по шагам

Инструкция для случая «только что поставил OpenWrt и ничего не знаю». Всё делается из
браузера, даже с телефона; отдельный SSH-клиент не нужен.

### 1. Включите терминал в LuCI

В LuCI откройте **Службы → Terminal** (в русской локали — «Терминал»).

Если такого пункта нет — его надо поставить:

1. **Система → Программы** (System → Software);
2. кнопка **«Обновить списки»** (Update lists), дождитесь конца;
3. в поиске наберите `luci-app-ttyd`, нажмите **«Установить»**;
4. обновите страницу LuCI (F5). Пункт **Службы → Terminal** появится.

Если меню так и не появилось — перезагрузите роутер (**Система → Перезагрузка**): пакет
включает службу при установке, но LuCI иногда держит старое меню в кэше.

### 2. Войдите в терминал

**Службы → Terminal**. Логин — `root`, пароль — тот, с которым вы входите в LuCI.

Признак, что всё получилось: внизу чёрного окна появилась строка вида

```
root@OpenWrt:~#
```

Дальше команды вставляются в это окно целиком (правой кнопкой мыши → «Вставить» или
долгое нажатие на телефоне), после каждой — Enter.

### 3. Поставьте базу: mihomo и magitrickle

geomask — надстройка: он настраивает mihomo и MagiTrickle, но не заменяет их. Без них
установщик честно остановится на первом шаге.

Два обычных пути:

- **из пакета «Запрет-менеджер»** — он ставит базовый стек (mihomo, magitrickle, zapret,
  hev-socks5-tunnel) вместе с LuCI-приложением;
- **по отдельности** — если вы ставите mihomo и magitrickle из своего набора пакетов;
  тогда для AI-пути и AI-DNS нужен ещё `hev-socks5-tunnel` (он создаёт туннельные
  интерфейсы), иначе установщик предупредит, что эти модули работать не смогут.

Проверить, что база на месте:

```sh
command -v mihomo; command -v magitrickled
```

Обе команды должны напечатать путь (например `/usr/bin/mihomo`). Если вместо этого пусто —
база не установлена, вернитесь к этому шагу.

### 4. Скачайте установщик и посмотрите отчёт

```sh
wget -O /tmp/geomask.sh https://github.com/kabzon93region/geomask/releases/latest/download/geomask.sh
sh /tmp/geomask.sh --check
```

Если `wget` нет (бывает на минимальных прошивках), скачайте тем же способом, что есть:

```sh
uclient-fetch -O /tmp/geomask.sh https://github.com/kabzon93region/geomask/releases/latest/download/geomask.sh
```

`--check` **ничего не меняет** — только читает и печатает отчёт по семи шагам. Смотрите на
пометки: `[FAIL]` — чего не хватает, `[WARN]` — на что стоит обратить внимание.

### 5. Установите

```sh
sh /tmp/geomask.sh --auto
```

Установщик сам поставит `python3`, `curl` и (для AI-DNS) `https-dns-proxy`, настроит mihomo,
списки, панель и служебные проверки. Обычно занимает 2–5 минут.

Идёт по шагам и **останавливается на первом FAIL**, объясняя, что именно не так — поэтому
если что-то пошло не так, читайте последнюю строку с `[FAIL]`, а не весь вывод.

### 6. Откройте панель

LuCI → **Службы → Гео-маскировка и AI** (если страница не появилась — Ctrl+F5).

Дальше стоит заглянуть в две вкладки:

- **Обзор** — состояние путей VPN / VPN-noP2P / AI и журнал;
- **Диагностика** — проверки модулей, роутера и сети, а также «маршрут домена»: введите
  любой адрес и увидите, через какую группу, правило и узел он пойдёт.

### Если что-то не получилось

| что видно | что делать |
|---|---|
| `[FAIL] mihomo: MISSING` | не установлена база — вернитесь к шагу 3 |
| `[FAIL] magitrickle: MISSING` | то же: нужен MagiTrickle (обычно ставится вместе с mihomo) |
| `[FAIL] no apk/opkg` | это не OpenWrt или прошивка без пакетного менеджера |
| `[FAIL] internet` | роутер без интернета; пакеты поставить неоткуда |
| `apk add ... failed` | нет места или нет сети: `df -h /` и проверьте WAN |
| панель не открылась | в терминале `/etc/init.d/rpcd reload`, затем Ctrl+F5 |
| что-то сломалось | восстановление: **Система → Резервная копия / Обновление прошивки → Восстановить** |

Перед любыми правками на роутере делайте полный бэкап — установщик умеет это одной командой:

```sh
sh /tmp/geomask.sh --backup
```

## Режимы установщика

Для тех, кто уже знает, что делает:

| команда | что делает |
|---|---|
| `--check` | только чтение: отчёт по семи шагам, ничего не меняет |
| `--auto` | все шаги без вопросов, стоп на первом FAIL |
| `--step N` | один шаг: 1 env, 2 geo, 3 subs, 4 aidns, 5 sync, 6 services, 7 verify |
| `--modules=core,luci,guard,path_vpn` | набор модулей без интерактивного меню |
| `--reinstall` | переустановка поверх (файлы, панель, модули) |
| `--backup` | полный `sysupgrade -b` и выход |
| `--adopt-config` | взять существующий (не от geomask) конфиг mihomo под управление |
| `--seed-lists` | восстановить доменные списки MagiTrickle из шаблона |
| `--restart` | разрешить перезапуск mihomo/magitrickle там, где он нужен (VPN рвётся на ~3 с) |

Без `--restart` установщик не перезапускает mihomo. `--auto` требует `--vpn-url`
(или уже настроенную подписку): без неё установка останавливается до первой записи.

Перед первым изменением на роутере установщик делает **полный** бэкап (`sysupgrade -b`),
проверяет, что архив читается, и останавливается, если бэкап не создался. Обновление из
панели ведёт себя так же: старые копии не удаляются до тех пор, пока новый архив не
проверен. Чужой конфиг mihomo не перезаписывается: для этого
нужен явный `--adopt-config`, иначе установка остановится и объяснит выбор.

## Панель

LuCI → «Гео-маскировка и AI», девять вкладок:

**Обзор** (состояние путей, журнал) · **Устройства** (режимы: туннель / исключение /
AI) · **Подписки** (VPN и AI, обновление, переключение) · **Списки и синк** (группы
MagiTrickle, шаблоны) · **Узлы подписки** (аудит серверов) · **Диагностика** ·
**Бэкапы** · **Модули** (версии и обновление частей + релиз целиком) · **Настройки**.

## Модули

Пятнадцать модулей, у каждого своя версия и отдельное обновление:

`core` (ядро: синк, node-audit, лейн, списки) · `luci` (админка: страница, бэкенд, RPC,
ACL, меню) · `guard` (сторож маршрута после `ifup`) · `path_vpn` · `path_vpn_nop2p` ·
`path_ai` · `ai_dns` · `youtube` · `torrent` · `diagnostic` · `doctor` · `device_modes` ·
`backup_share` · `self_update` · `admission_service`.

Версия модуля — это релиз, в котором он последний раз менялся (например `core 1.27.10`,
`youtube 1.22.5`, `doctor 1.30.7`). Набор выбирается при установке (`--list-modules`,
`--modules=`); снятый модуль остаётся видимым в панели со статусом «не выбран» и не
обновляется. Подробности — [docs/MODULES.md](docs/MODULES.md).

## Диагностика

Вкладка «Диагностика» (модуль `doctor`) отвечает на вопрос «почему этот сайт идёт не туда»
без консоли:

- проверки по каждому модулю, по роутеру, сети и путям — с вердиктом и строкой «что делать»;
- **маршрут домена**: DNS → группа MagiTrickle → правило mihomo → узел и страна выхода →
  живой HTTP-запрос → **связанные хосты** (редиректы, ссылки, формы, iframe, SAN
  сертификата), у каждого — свой путь и страна;
- каждый прогон пишется в свой лог (`/root/geomask-logs`), логи живут 7 дней.

Проверки только читают состояние: если что-то можно починить безопасно, инструмент
подскажет команду, но сам конфиги не переписывает. Подробности —
[docs/DIAGNOSTICS.md](docs/DIAGNOSTICS.md).

## Обновления

Роутер берёт релиз с GitHub и принимает его только если сходится всё: `GM_VERSION` внутри
файла равен тегу, а sha256 — digest ассета. Перед установкой делается полный
`sysupgrade -b`, сервисы не перезапускаются.

Публикация релиза — `tools/release.py` (`status`, `publish`, `verify --full`, `drift`):
он прогоняет тесты, ставит тег, создаёт релиз с ассетом `geomask.sh` и сверяет digest.
Порядок и контракт описаны в [docs/RELEASING.md](docs/RELEASING.md).

## Ограничения

- geomask не устанавливает прошивку, не настраивает WAN/PPPoE и не заменяет `mihomo`:
  он приводит существующий стек в рабочее состояние и объясняет расхождения.
- Любое изменение на роутере — только после свежего полного `sysupgrade -b`, сохранённого
  на ПК. Восстановление LuCI возвращает настройки, но не произвольный сервисный код.
- Правки конфига mihomo проверяются `mihomo -t` до применения; установщик не применяет
  конфиг, который не прошёл проверку.

## Разработка

```text
geomask.sh.in   шаблон установщика — редактируемый источник
assets/         бэкенд, rpcd, ACL, страница панели, sync/guard, диагностика
build.py        сборка: подстановка ассетов и версий
geomask.sh      собранный артефакт (в git; вручную не редактируется)
modules/        манифесты модулей и каталог modules/index.json
tools/          сборка каталога, RPC-генератор, релизы, экспорт списков
tests/          unit-тесты (python) и песочница (sh)
docs/           справки, release notes, исторические планы и SPEC
```

```sh
python build.py                     # собрать geomask.sh
python tools/build_module_index.py  # каталог модулей
python tools/check_build.py         # артефакт == сборка
python -m unittest discover -s tests -p 'test_*.py'
bash tests/run_tests.sh             # песочница
```

CI (`.github/workflows/ci.yml`) на каждый push проверяет сборку, RPC-манифест, синтаксис,
python-тесты и песочницу.

## Секреты и бэкапы

В репозитории нет подписочных ссылок, UUID, ключей и паролей — это проверяется тестами и
сканированием релизного артефакта. Полные конфиги и архивы бэкапов остаются на ПК; на
роутере допустима одна свежая копия (`/root/geomask-backups`), которую отдаёт read-only
SMB-шар `geomask-backups`.
