# geomask v1.7.0 — самообновление из панели LuCI

**Дата:** 2026-10-23. **Тип:** фича (MINOR). Назначение: обновлять geomask и его админку
прямо из интерфейса панели «Гео-маскировка и AI» — по образцу Zapret-Manager.

## Что появилось

**Блок «Обновления» внизу страницы** (редко используемый раздел — поэтому внизу):

- **Строки geomask** с локальной и доступной версией: `geomask (ядро)` (из установленного
  `/tmp/geomask.sh`), `Админка LuCI` (версия внутри `main.js`), `geomask-guard` (версия внутри
  скрипта). Версии компонентов вставляет `build.py` из `GM_VERSION` — расхождение
  «панель≠бэкенд»/«локальная новее релиза» видно сразу.
- **Доступно на GitHub**: последний релиз (`releases/latest`, кэш 1 час) + бейдж
  «доступно обновление» / «актуально».
- **Стек (справочно, без кнопок)**: mihomo (реальная версия `mihomo -v`), magitrickle,
  hev-socks5-tunnel, tg-ws-proxy, https-dns-proxy, zapret/nfqws (дата файла).
- Кнопка **«Проверить ещё раз»** — вне кэша.

**Кнопка «Обновить до vX.Y.Z»** (видна только когда есть что обновлять):

1. **Свежий полный бэкап** `sysupgrade -b` (инвариант проекта) — файл и md5 остаются в
   `/tmp/geomask-upd/backup.info`, показываются в статусе.
2. Скачивание `geomask.sh` релиза: jsDelivr `@тег` → fallback GitHub Releases.
3. Валидация: `sh -n`, совпадение `GM_VERSION` с тегом, **sha256 = digest GitHub-релиза**
   (если проверка шла через API; при фолбэке на raw — только синтаксис+версия).
4. Установка `--reinstall --yes` **отсоединённым процессом** (rpcd-бэкенд в процессе не
   убивается): файлы модулей/панели/guard/hotplug/cron, **без перезапуска сервисов**;
   затем `rpcd reload`, чтобы подхватились новые ubus-методы.
5. Панель опрашивает статус каждые 2 с: `backup → download → validate → apply → done`;
   на «Готово» — кнопка «Обновить страницу» (Ctrl+F5 — браузерный кэш JS).

Старые версии панели блока «Обновления» не имеют (каскад): первый раз новая панель
ставится обычным способом (синк/установщик), дальше обновления идут кнопкой.

## Что не входит (фаза 2, после теста)

Замена бинарей стека (mihomo/magitrickle/…) и рестарты их сервисов из панели — отдельным
этапом. Версии стека в этой версии — только справочные.

## Обновление

```sh
# панелью: «Гео-маскировка и AI» → внизу «Обновления» → «Обновить до v1.7.0»
# или вручную:
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh --reinstall --yes
```

После обновления: `sh /tmp/geomask.sh --check` → ожидается 7/7; в панели версии = `1.7.0`.
