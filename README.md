[![Base](https://img.shields.io/badge/base-v1.25.3-blue)](https://github.com/kabzon93region/geomask/releases/tag/v1.25.3)

Конфигуратор домашнего стека маршрутизации и обхода блокировок на OpenWrt. Целевой стенд — **wwGate AX3000, MediaTek Filogic/aarch64**, в сохранённой документации OpenWrt 25.12.5. Это не обещание поддержки всех устройств и версий OpenWrt.

## Назначение компонентов

| Компонент | Ответственность |
|---|---|
| LuCI / rpcd `geo-sync` | Панель статусов, подписок, режимов устройств и операций |
| mihomo | Группы и правила путей VPN/VPN-noP2P/AI |
| MagiTrickle → mihomo sync | Генерация rulesets из доменных групп; событийный syncd и cron-страховка |
| hev-socks5-tunnel | TUN→SOCKS тракты; интерфейсы создаёт hev, не сам mihomo |
| AI-DNS | Выделенный DNS-тракт AI-устройств; перенос исправленного SOCKS5h DoH в шаблон |
| guard / проверки | Поддержание существующих правил и диагностика с известными ограничениями |

**Подписка** — источник узлов, **путь** — политика/транспорт, **модуль** — возможность релиза. Их количество не обязано совпадать. Провайдер определяется из группы, а не постоянным соответствием `sub/de5`. Самостоятельный выбор AI-подписки сохраняется.

Целевая v2 требует подходящий узел выбранного пути или BLOCKED, AI только US с AND обязательных сервисных доказательств, P2P только через выделенный ingress. Это **требования**, а не уже подтверждённое поведение текущего стека. Строгую политику нельзя включать незаметно при миграции формата.

## Установка и обновление: ограничения

**Не запускать текущую рабочую копию или слепой `--reinstall` на production.** Сначала согласованная группа изменений, проверки и независимый откат. На новой установке необходим готовый сторонний стек; geomask v2 не обещает установку прошивки, WAN/PPPoE и всех сторонних программ.

Перед любой записью/рестартом на роутере обязателен свежий полный стандартный `sysupgrade -b`, сохранённый на ПК с проверенной суммой. Для mihomo — проверка кандидата `-f ... -t` **и** изолированный runtime trial на других портах/ресурсах до live apply, затем независимая проверка runtime и отката. Одна `.bak`-копия или наличие helper-а предусловие не заменяют.

Способы запуска и прежние команды — в [OPERATIONS](docs/OPERATIONS.md); техническая справка не отменяет [правила проекта](../AGENTS.md) и условия основного плана. Семь verify-шагов и успех в песочнице не заменяют клиентский E2E.

## Разработка

```text
geomask.sh.in   шаблон установщика — редактируемый источник
assets/        backend, rpcd, ACL, LuCI-view, sync/guard и прочие ассеты
build.py       сборщик шаблона и ассетов
geomask.sh     generated artifact; вручную не редактируется
tools/         генератор RPC и новые частичные helper/model/CLI
modules/       локальные манифесты; не доказанный жизненный цикл модулей
tests/         публичная песочница и unit-тесты
sandbox/       локальная песочница
docs/          технические справки, основной план, SPEC и отчёты
```

Сборка: `python build.py`. Проверка RPC: `python tools/gen-geo-rpc.py --check`. **`tools/check_build.py` пересобирает artifact на месте**: baseline/проверку drift выполнять в отдельной копии, не прятать расхождение предварительной пересборкой. Текущий CI и предложенный новый workflow — разные вещи. Коммиты/push/release только по отдельному запросу.

## Секреты и восстановление

Секреты, полные runtime-конфиги и архивы не публикуются. История бэкапов на ПК; единственная свежая копия на роутере допустима только действующим исключением. Гостевой backup-share — известный риск, не настройка по умолчанию для новой установки.

Стандартный LuCI/sysupgrade-архив сохраняет настройки, **но не весь кастомный service-код**. Дополнительные точные snapshots зарегистрированы на этапе 0; комплексный restore-дрилл не выполнен. Нельзя обещать полное восстановление всех программ одним Restore в LuCI.
