## geomask v1.4.4

Кнопки назначения подписок + ручной режим переустановки панели.

### Панель «Подписки»

- Кнопки `→ VPN` / `→ AI` теперь действительно активны (не disabled).
- У подписки, уже назначенной на VPN, кнопка «→ VPN» подсвечена **синим**
  (в цвет плашки VPN); на AI — **зелёным** (в цвет плашки AI); неактивные
  кнопки — нейтральные. По кнопкам сразу видно, какой режим выбран.

### Главное меню

- Новый пункт **3) Панель Гео (переустановить/обновить)** — ручной режим
  переустановки/обновления панели управления без полного пересета
  (mihomo не трогается).
- Ручные режимы, которые уже есть: `--check` (диагностика только чтение),
  `--step N` (один шаг), «Пошаговый мастер» (пункт 2: статус шагов и запуск
  любого по номеру), `--reinstall` (полный сброс-установка), `--backup`.

### Установка

```sh
curl -fL -m 60 -o /tmp/geomask.sh 'https://cdn.jsdelivr.net/gh/kabzon93region/geomask@master/geomask.sh' && sh /tmp/geomask.sh
```
